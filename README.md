# منصة اختبار الرياضيات التفاعلية (Math Exam Platform) 📐

منصة متطورة وشديدة الأناقة مصممة بـ **React + Vite** لإجراء اختبار رياضيات شامل مكون من **25 سؤالاً** مع نظام توقيت دقيق وحماية من إعادة الدخول وملاءمة كاملة لجميع الشاشات والأجهزة.

---

## ✨ المميزات الرئيسية للمشروع

1. **تصميم فائق الشياكة (Ultra-Modern UI):**
   - واجهة داكنة مريحة للعين مستوحاة من Glassmorphism وتدرجات النيلي والبنفسجي.
   - خطوط عربية فائقة الوضوح والجمال (`Cairo` و `Tajawal`).
   - تأثيرات حركية سلسة وتأثير احتفالي بالألعاب النارية (Confetti) عند اجتياز الامتحان.

2. **تسجيل اسم الطالب والبيانات:**
   - شاشة ترحيب ودخول تطلب من الطالب إدخال اسمه ثلاثياً أو رباعياً، مع كود اختياري.
   - عرض قواعد الامتحان بوضوح تام قبل بدء الوقت.

3. **توقيت محدد بدقة (60 دقيقة / ساعة كاملة):**
   - عداد تنازلي مستمر يظهر في الشريط العلوي (الساعات : الدقائق : الثواني).
   - تغير ديناميكي لألوان العداد (أخضر > 15 دقيقة، برتقالي تحذيري 5-15 دقيقة، أحمر نابض < 5 دقائق).
   - **تسليم تلقائي فوري** للاختبار عند انتهاء الوقت حتى لو لم يضغط الطالب على زر التسليم.
   - الحساب يعتمد على التوقيت الفعلي `Date.now()`، مما يمنع التحايل بتحديث الصفحة أو إغلاقها.

4. **منع الدخول مرة أخرى (قاعدة الدخول لمرة واحدة):**
   - بمجرد بدء الاختبار وتسليمه، يتم حفظ النتيجة وتأمين الامتحان عبر التخزين المحلي `localStorage`.
   - محاولة إعادة الدخول تعرض رسالة قفل وتمنع الطالب من أداء الامتحان مجدداً مع إظهار نتيجته المسجلة.
   - **خاص بالمشرف / المعلم:** يوجد زر صغير سري أسفل الشاشة لإعادة تصفير المحاولة للتجربة باستخدام كلمة المرور: `reset2026`.

5. **تجاوب كامل 100% (Fully Responsive):**
   - تم ضبط التصميم ليعمل بسلاسة فائقة على:
     - الهواتف الذكية بجميع أحجامها (أزرار لمس مريحة، قائمة سفلية مرنة للأسئلة).
     - الأجهزة اللوحية (Tablets & iPads).
     - الحواسيب المكتبية والشاشات العريضة.

6. **لوحة تحكم وتتبع الأسئلة (1 إلى 25):**
   - شبكة أرقام الأسئلة مع ألوان لحالات الأسئلة:
     - 🟢 مجاب عليه (Answered)
     - 🟡 مميّز للمراجعة (Flagged for review)
     - ⚪ لم يُجب بعد (Unanswered)
     - 🟣 السؤال الحالي النشط
   - شريط تقدم مئوي علوي يوضح نسبة إنجاز الامتحان لحظياً.

7. **ملخص النتيجة وإمكانية المراجعة:**
   - عرض الدرجة بالنسبة المئوية وعدد الإجابات الصحيحة والخاطئة والوقت المستغرق.
   - إمكانية فتح قائمة مراجعة الأسئلة للاطلاع على الإجابة النموذجية وتفسير كل مسألة.
   - زر مخصص لطباعة النتيجة / الشهادة بصيغة منسقة.

## 🚀 طريقة تشغيل المشروع

افتح موجه الأوامر (Terminal / PowerShell) داخل مجلد المشروع:

```bash
cd math-exam-app
npm install
npm run dev
```

ثم افتح الرابط في المتصفح:
```
http://localhost:5173
```

## 📝 كيفية استبدال الأسئلة والأجوبة بأسئلتك الخاصة

الأسئلة والحلول مرتبة بشكل منظم جداً داخل الملف:
`src/data/questions.js`

يمكنك ببساطة تعديل أو استبدال مصفوفة `INITIAL_QUESTIONS` بالأسئلة الخاصة بك بهذا الشكل:

```javascript
{
  id: 1,
  topic: "الجبر", // اسم الدرس أو الفرع
  question: "نص السؤال هنا...",
  formula: "x² + 2x + 1 = 0", // اختياري: معادلة رياضية تظهر في صندوق مميز
  options: [
    { id: "A", text: "الخيار الأول" },
    { id: "B", text: "الخيار الثاني" },
    { id: "C", text: "الخيار الثالث" },
    { id: "D", text: "الخيار الرابع" }
  ],
  correctAnswer: "A", // الحرف الصحيح (A أو B أو C أو D)
  explanation: "شرح الحل النموذجي..." // يظهر في صفحة المراجعة بعد انتهاء الاختبار
}
```
